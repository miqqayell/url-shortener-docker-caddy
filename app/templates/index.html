About this project

A small multi-container demo built for the Infrastructure 3 course. The site you are looking at is a Python URL shortener that stores every short link, click counter and recent-link list in Redis.

All traffic terminates at a Caddy reverse proxy, which automatically obtains a public TLS certificate from Let’s Encrypt using a DNS-01 challenge against DuckDNS. Caddy uses path-based routing to send /git/* to a self-hosted Gitea instance and everything else here, to the Flask app.

Caddy Flask + Gunicorn Redis Gitea Docker Compose Let’s Encrypt DuckDNS DNS-01
